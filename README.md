# 🎓 B.Tech YouTube Lecture Notes Generator

An automated tool to transform engineering YouTube lecture videos into structured, semester-exam-ready revision notes and MCQs using the Google GenAI SDK and `gemini-3.8-flash`.

---

## ✨ What It Generates
- **📌 Problem Statement & Overview** (<150 words)
- **📝 Crisp Technical Notes:** Definitions, system architecture, formulas, and Big-O complexity tables.
- **🎯 University Exam Questions:** 2–3 mark viva questions and 5–10 mark descriptive/numerical problems.
- **⚡ Self-Assessment:** 5 GATE/semester-level MCQs with rationales.

---
